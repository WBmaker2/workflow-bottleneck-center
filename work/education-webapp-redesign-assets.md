# 리디자인 자산 안전 기록

기록일: 2026-08-30

## 현재 자산 인벤토리

| 경로/사용 | 분류 | 조치 | 접근성·권리 메모 |
|---|---|---|---|
| `public/favicon.svg` / `index.html` favicon | 브랜드 식별 자산 | 보존, 교체하지 않음 | 브라우저 탭 식별용이며 학생 학습 내용의 근거로 사용하지 않음 |
| `src`·CSS의 이미지 사용 | 해당 없음 | 새 `<img>`, CSS 배경, 외부 이미지 추가하지 않음 | 이미지 대체 텍스트·외부 요청을 늘리지 않음 |
| 관계 SVG `src/features/relations/RelationBoard.tsx` | 데이터 기반 도식 | 보존, 모바일에서는 숨김 가능한 보조물로 유지 | 작업 의미는 문장 목록이 주 경로이며 SVG에 판정을 의존하지 않음 |

## 생성 모델 사용 여부

이번 리디자인에는 일반 장식·개념 이미지가 필요하지 않습니다. `imagegen`은 호출하지 않았습니다. 새로 만든 이미지가 없으므로 생성 프롬프트, 생성일, 모델, 라이선스, 크레딧, 원본 보관 경로도 없습니다.

사실·정체성·증거 자산(시나리오 작업 조건, 관계 도식, 시간표, 로고)은 자동 생성하거나 교체하지 않습니다. 이미지가 추가되는 후속 변경은 이 문서에 자산 분류, 사용 위치, 대체 텍스트, 축소·대체 동작을 먼저 기록해야 합니다.

## 2026-08-30 재검토

상태 강조 테두리와 근거 진행률 스타일만 보완했으며 이미지 경로·이미지 사용 위치·자산 분류에는 변화가 없습니다. `imagegen`은 이번 재검토에서도 호출하지 않았습니다.
