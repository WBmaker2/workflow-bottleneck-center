# Elementary Web App Simulation Decision

판단일: 2026-08-31

## 결정

새 시뮬레이션(2D 장면, 3D 장면, 게임형 캐릭터)을 추가하지 않습니다. 기존 `SimulationScreen`은 작업 시작·종료·기다림·일시정지·분석 진입을 가상 시간으로 보여 주며, `[6실05-01]`의 순서와 조건 표현 목표에 직접 연결됩니다.

## 기존 기능 점검

| 점검 항목 | 현재 계약 | 처리 |
|---|---|---|
| 학습 필요성 | 관계와 일정의 결과를 관찰해야 함 | 유지 |
| 상호작용 | 정상 모드 자동 실행, reduced-motion 수동 `다음 단계` | 유지 |
| 판정 | `AttemptSnapshot`, `WaitReason`, 병목 분석 결과 사용 | 변경하지 않음 |
| 접근성 | 상태 live region, 버튼 이름, 정적 reduced-motion | 기존 테스트 유지 |
| 개인정보 | 이름·계정·서버·음성 없음 | 새 수집 없음 |
| 자산 | 기능 이해에 장식 이미지 불필요 | imagegen 실행하지 않음 |

## 이번 개선과의 연결

이번 변경은 시뮬레이션 자체가 아니라 시뮬레이션에 들어가기 전 `조건 확인`을 찾는 시간과 실행 전 예측 입력의 안내 일치를 개선합니다. 실행 결과의 기다림 원인·안전·품질·공정성 의미는 그대로 둡니다.

## 향후 수용 기준

새 장면을 추가해야 하는 경우에는 먼저 해당 장면이 텍스트·현재 시간·기다림 원인을 더 잘 이해하게 하는지 확인하고, 이미지가 사실·지도·차트·로고·증거 자산인지 분류합니다. 이번 작업에는 그 필요성이 관찰되지 않았습니다.
